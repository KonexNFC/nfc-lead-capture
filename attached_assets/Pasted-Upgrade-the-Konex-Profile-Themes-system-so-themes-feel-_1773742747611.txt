Upgrade the Konex Profile Themes system so themes feel materially different and support controlled user customization.

IMPORTANT
Do not rebuild the entire Appearance feature.
Do not remove existing draft/publish, theme locking, or preview functionality.
Do not redesign unrelated app areas.
Keep the current architecture based on one shared profile renderer and config-based themes.

CURRENT ISSUE
The current themes are too visually similar.
Switching between the free themes does not create a clearly different profile experience.
The system currently feels like color swapping, not true theming.

GOAL
1. Make each theme visually and structurally distinct
2. Add curated theme customization controls
3. Keep everything brand-safe and scalable
4. Preserve one shared renderer with theme tokens and layout variants

THEMES TO IMPROVE
- minimal_corporate
- personal_brand
- luxury_black

REQUIRED THEME DIFFERENTIATION
Update each theme so they differ across multiple dimensions, not just color.

Minimal Corporate should feel:
- clean
- structured
- restrained
- professional
Use:
- tighter spacing
- flatter surfaces
- smaller border radius
- simpler CTA styling
- more formal typography pairing
- more disciplined section rhythm

Personal Brand should feel:
- expressive
- approachable
- creator-led
- modern
Use:
- softer shapes
- larger avatar emphasis
- more generous spacing
- more vibrant accent treatment
- stronger headline styling
- friendlier CTA treatment
- optional gradient or warmer header treatment

Luxury Black should feel:
- premium
- elegant
- dark
- high-end
Use:
- dark surfaces
- elevated cards
- refined contrast
- premium typography pairing
- richer shadows
- more dramatic spacing
- luxury accent handling

DO NOT create separate hardcoded profile pages for each theme.
DO use one shared renderer with configurable layout and token differences.

ADD CUSTOMIZATION CONTROLS
Create a controlled customization panel inside Appearance for the selected theme.

2. Button style

   - sharp
   - soft
   - rounded
4. Spacing density

   - spacious
5. Header style
   - centered
   - left-aligned
   - banner
6. Font style
   - modern
   - elegant
   - bold

Not every theme must support every option.
Each theme config should declare what customization controls it supports.
Only show controls that the selected theme supports.
