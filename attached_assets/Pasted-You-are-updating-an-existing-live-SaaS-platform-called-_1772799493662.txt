PHASE 2 — NFC TAP ROUTER
==================================================

Create a new public route:

/t/:cardCode

Behavior:
1. look up the card by card_code
2. if card does not exist, show branded “Card not found” page
3. if card exists but status = unassigned:
   redirect to activation flow
4. if card exists but status = suspended or lost:
   show branded inactive card page
5. if card exists and is active:
   determine destination profile/page
   log a card_tap_event with event_type = nfc_tap
   increment card.tap_count
   update last_tap_at
   redirect to the linked public profile page

If profile exists, destination should resolve to current public profile URL format already used in the app, for example:
/u/top

Do not break existing public profile links.

PHASE 3 — ACTIVATION FLOW
==================================================

Create a new branded activation flow:

/activate/:cardCode

Logic:
- if user is not logged in:
  prompt login or signup first
- after auth, resume activation automatically
- if card is already assigned to the logged-in user:
  show success state and option to go to My Cards
- if card is assigned to someone else:
  block activation and show support message
- if card is unassigned:
  assign owner_id = current user
  status = active
  activated_at = now
  auto-link card to the user’s primary profile
  create assignment history entry
  show success screen

Activation success screen copy:
Headline: “Your Konex card is now active”

Buttons:
- View My Card

- View Public Profile
