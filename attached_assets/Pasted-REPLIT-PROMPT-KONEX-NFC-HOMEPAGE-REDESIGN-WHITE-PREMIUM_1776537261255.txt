REPLIT PROMPT — KONEX NFC HOMEPAGE REDESIGN (WHITE / PREMIUM UI)

Prompt

Build a modern, high-converting marketing website for KONEX NFC, transforming the current dark AI-style interface into a clean, bright, premium, Apple-level aesthetic.

Design Direction

* Replace dark backgrounds with white / off-white (#FFFFFF / #F8F9FB)
* Use subtle greys for structure (#E5E7EB / #F1F5F9)
* Keep a single strong accent color (electric blue or deep purple) used sparingly for CTAs and highlights
* Overall feel: minimal, premium, tech-forward, lifestyle + SaaS hybrid
* Inspiration: Apple, Stripe, Notion, Linear

⸻

Core Principles

* Prioritise clarity over complexity
* Make it feel like a real product company, not a dev tool
* Focus on conversion + storytelling
* Mobile-first design
* Smooth spacing, large typography, strong hierarchy

⸻

Typography

* Font: Inter or SF Pro style
* Headings: bold, large, confident
* Body: clean, readable, high spacing
* Generous whitespace throughout

⸻

UI DETAILS

* Buttons:
    * Rounded (8–12px radius)
    * Solid accent color for primary
    * Ghost style for secondary
* Cards:
    * Light shadows
    * Subtle borders (#E5E7EB)
* Sections:
    * Clear spacing (80–120px padding)

⸻

ANIMATIONS (SUBTLE ONLY)

* Fade-in on scroll
* Slight hover lift on cards
* Smooth transitions (no flashy effects)

⸻

WHAT TO REMOVE

* Dark/black backgrounds dominating UI
* Overuse of gradients
* “AI app” styling
* Cluttered dashboard-like homepage
* Excess neon effects

⸻

END GOAL

A clean, bright, premium website that feels like:

* A real tech brand
* A lifestyle product
* A scalable SaaS platform

Not a prototype. Not an AI-generated app.
